# 每页规划

```text
第N页：
主题与读者收获：
标题：居中，最多2行，写出断行
栏目签：真实类别，贴在整页左上角
强调色：blue / yellow / orange，全套一致
主体：
下方组合：focus / pair / facts / facts-side / steps
各格真实内容与来源：
留白位置与理由：
照片及主体地图、object-position（如有）：
```

全套无衬线细字；数据可局部加粗；不编数字、不凑格子、不放假按钮。单页无阴影，多页总览可有轻阴影。

页面顶部只保留左上矩形栏目签，不增加“图文卡片”、组合说明、期号或版本号等横向小字行。页脚短出处和页码仍可保留。
