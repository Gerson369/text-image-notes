# 白色模块组件

| 类名 | 用途 |
| --- | --- |
| .title-zone | 居中的标题与一句导语 |
| .panel | 主面板：白底、直角、2px浅灰线，无投影 |
| .page-tab | 整页左上角贴边矩形栏目签；.card直接子元素，top:0、left:0，真实类别、22—24px |
| .hero | 核心解释/图片；格内留白，栏目签位于整页角落 |
| .modules[data-grid] | focus / pair / facts / facts-side / steps 五种组合 |
| .cell | 一个有意义的子模块，24—32px内距 |
| .side | 右侧跨两行通栏，放共同结论或下一步 |
| .num | 关键数据，可500—600字重；蓝字或黄/橙底深色字 |
| .body / .caption | 正文 / 说明文字，无衬线细字体 |
| .foot | 短出处或系列名＋页码，自然流排列 |

外框及共用网格线不按装饰组件计数。通常每页一个主面板、内部1—5个有用分区。不能把「主体内容区」「数据位置」「下方模块」写进真实成品；骨架教学示意图除外。
