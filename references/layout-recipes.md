# 按内容组合模块

配方是信息关系的选择，不是每页固定摆法。面板共用 `.panel`、`.hero`、`.modules` 与 `.cell`；整页栏目签 `.page-tab` 位于.card直接子层。

| 代号 | 下方组合 data-grid | 内容关系 | 取舍 |
| --- | --- | --- | --- |
| M01 | focus | 封面、一个观点或完整说明 | 合并格子，保留呼吸空间 |
| M02 | focus | 照片为主体 | 放在.hero，文字留在独立区 |
| M03 | pair | 一张图＋两项说明 | 下方双栏，不重复上方内容 |
| M04 | facts | 四项并列要点或指标 | 2×2；不足四项就换组合 |
| M05 | pair | 前后、两种做法、正反对照 | 两栏同级，比较维度一致 |
| M06 | facts-side | 四项指标＋共同结论 | 左2×2，右一列跨两行 |
| M07 | focus | 一句核心观点＋适用条件 | 不为金句额外增加第三行标题 |
| M08 | steps | 三步有顺序的动作 | 三行，每行「编号＋一个动作」 |
| M09 | pair | 主图＋两张细节图 | 每图有主体地图/裁切位置 |
| M10 | focus | 收尾与具体行动 | 一句可执行的话，信息少就留白 |

四格＋通栏用CSS Grid：三列 `1fr 1fr .65fr`、两行；`.side`指定第三列跨两行。右栏可放结论/限制/下一步，文字太多就改为底部全宽说明。

套图节奏：以读者理解为先；6页左右通常至少3种组合。没有信息关系就不强行凑版式数量。不要为了看起来多样而打乱步骤顺序。
