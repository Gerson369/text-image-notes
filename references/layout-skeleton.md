# 3:4布局骨架

固定阅读顺序和对齐线，让内容决定格子组合；不固定每页信息量。

默认左右88px、下方80px，标题区从y=148px开始，内容宽904px。用同一容器管理页边；页脚走正常文档流，不能与面板重叠。

| 区域 | 默认处理 | 可变部分 |
| --- | --- | --- |
| 页面左上角 | 仅保留贴边矩形栏目签 | 不加横跨顶部的栏目、期号、版本号小字行 |
| 标题与导语 | 居中，两行以内；标题与导语间24—40px | 一行标题可让出高度；导语不是必填项 |
| 标题到面板 | 32—64px，优先保证内容可读 | 不靠大片空洞制造高级感 |
| 主面板 | 直角白底、2px浅灰线；面板本身不再放栏目签 | 一个主体＋按内容组合的下方格子，或整块内容 |
| 页脚 | 短出处/系列名、页码；距面板≥24px | 长出处移到SOURCES.md，不编来源 |

模板使用三行网格：标题352px、内容自适应、页脚44px，行间32px。顶部148px留白为标题提供呼吸空间，不插入小字行。此值是两行大标题的起点。正文多时缩短标题区的无用留白；不能缩小文字来塞进预设格子。封面/金句页可合并主体和下方分区，保留栏目签与上下锚点。

面板内：主体区通常48px内距；小格24—32px内距。纯白空白占比以30%—45%为审美起点，不能当硬指标删掉必要信息。

## 格子怎样决定

先列出真实信息对象与关系，再选结构：两方对照用双栏；三步行动用三行；四项独立指标用四格；四项指标还有共同结论时用四格＋右侧通栏。无数据就用文字或合并，不能先画四格再编四个数。

整页左上角栏目签是.card的直接子元素，以整页画布为定位基准，top:0、left:0，与画布上沿、左沿贴齐。使用白底细线长方形，默认14px上下内距、24px左右内距；签中文字可进入页边安全区，这是唯一例外。其余标题、正文、页码仍遵守≥64px安全边距。标签不位于下方主面板内，不是胶囊或按钮，不加阴影，不能遮住标题。

同一套图的字体、边线、外边距和标签形式一致；主体占比和分格可以不同。不要把每页都排成「上方文字＋双数据＋下方结论」。
