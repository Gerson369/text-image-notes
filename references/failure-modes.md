# 常见失败与修法

| 现象 | 修法 |
| --- | --- |
| 每页都排成同样三段 | 先列信息关系，再选focus/pair/facts/facts-side/steps |
| 忘记左上角矩形签 | 补真实栏目，贴齐整页上沿、左沿；若签在主面板里，移至.card直接子层 |
| 为四格编四个数据 | 删除无依据格子、换组合；示例标明示意 |
| 右侧只有一个假按钮 | 换成真实结论/限制/下一步，没有就合并右栏 |
| 居中标题显得拥挤 | 缩短到两行，放大标题周围间距；不整句加粗 |
| 细字太淡 | 加深文字色，必要时400字重；仍保留无衬线细字体风格 |
| 黄/橙数字看不清 | 改为黄色/橙色底，深色字 |
| 分格线断裂或错位 | 共享CSS Grid，别用空格或字符框排版 |
| 标题压脸 | 图片分区，重查主体地图和object-position |
| 内容越界 | 删字、合并或拆页，不靠裁切遮住 |
| 总览像无缝拼图 | 加外留白、卡间距、细边框和轻阴影 |
