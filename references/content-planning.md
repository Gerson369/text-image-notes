# 内容规划

## 压缩阶梯

1. 核心一句：这篇到底说什么。
2. 读者收获：划完这组图能得到什么。
3. 段落地图：3–8 个点。
4. 每页一句：具体、有动作或后果。
5. 必要的字：只留让画面成立的字，其余进正文区。

## 页数

| 原文 | 建议 |
| --- | --- |
| ≤ 300 字 / 只有照片 | 封面 + 2–3 页 |
| 300–1000 字 | 封面 + 4–6 页 |
| > 1000 字 | 封面 + 6–8 页，其余写进正文 |

## 分页计划模板

```text
标题：
立场 / 色板：
照片：
01 封面｜标题｜栏目签｜核心一句｜模块组合｜用哪张图
02 ……｜标题｜栏目签｜必要的字与数据出处｜模块组合｜留白位置
```

## 文案

- 标题说人话：「洱海边住了三天」优于「大理之旅」。
- 不写空标签（「背景介绍」「总结」），写内容本身。
- 句子清楚、简练，标题居中且最多两行；解释放导语，不靠加粗整段建立层级。
- 不把「三连拼图」「留白处理」这类制作术语写上卡面。
