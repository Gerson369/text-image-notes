# 白底细线模块风格

纯白画布；居中的两行以内大标题；全套无衬线细字；整页左上角贴边矩形栏目签；下方白色直角模块用浅灰细线分格；关键数据以蓝/黄/橙中的一种强调。

统一外边距、线色、字重与栏目签，主体和下方分格按内容关系变化。留白位于标题周围、格内和页边。禁止为填满版面凑指标、加假按钮。

单张卡片平面呈现，无渐变、无投影；多页总览的卡片外部可有细边框与轻阴影。两者分别检查，不能因为总览允许阴影就给单页格子加阴影。

身份测试：纯白；细无衬线；标题居中≤2行；整页左上矩形栏目签；可见且连续的细分格线；数据强调有理由；有呼吸空间。校验器检查基本样式与几何关系，人工检查是否清楚、是否适合手机阅读。

页面顶部只保留左上矩形栏目签，不增加“图文卡片”、组合说明、期号或版本号等横向小字行。页脚短出处和页码仍可保留。
